# GeoQuest 3D — Petualangan Bangun Ruang (frontend)

Frontend statis (HTML/CSS/JS murni, tanpa build) untuk GitHub Pages. Backend: Google Apps Script REST API (`Kode.gs`, terpisah).

1. Isi `GAS_URL` di `js/config.js`.
2. Push folder ini (yang berisi `index.html`) ke GitHub, aktifkan Pages (branch `main`, folder root).

Panduan lengkap: **PANDUAN-INSTALASI.md**.
